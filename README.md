# 鳩特獎學金榮譽照工作室

純前端獎學金頒獎照產生器。選取真實照片、填寫姓名與成績，套用「榮耀金」或「溫暖表揚」外框，下載 JPG／PNG。圖片文字只包含學生姓名與頒獎名目，沒有獎金金額。

## 功能

- 段考高分／進步／名次、會考模考等第／名次、學測模考級分／進步、自訂表揚。
- 依所選獎項顯示需要的欄位，檢查有效成績與門檻，產生可修改的名目。
- 姓名一鍵隱碼；拖曳照片、縮放、重設構圖；預覽照片可用方向鍵微調。
- 1080 × 1350 貼文、1080 × 1080 正方形、1080 × 1920 限時動態，分別排版。
- 本機 Canvas 合成與高畫質匯出，支援裝置可使用檔案分享。
- 無第三方程式、追蹤碼、API、雲端上傳或永久儲存的學生資料。照片不會進入此 repo。關閉頁面後需重新選取照片。

## 獎項依據

目前預設依使用者提供的「114 上學期獎學金制度」，並非自動更新的現行公告。

| 獎項 | 門檻 |
| --- | --- |
| 段考高分 | 90～99 分、100 分 |
| 段考進步 | 進步至少 20 分 |
| 段考及會考模考名次 | 校排 1～10 名、班排 1～3 名 |
| 會考模考等第 | A、A+、A++ |
| 學測模考級分 | 13、14、15 級分 |
| 學測模考進步 | 單科進步至少 5 級分 |

方案中的兌換資料要求：分數制須考卷、名次制須獎狀、等第／級分制須成績單；所有申請須申請單。工具僅協助製圖，沒有審核或計算累計獎金。規則集中於 `awards.js`，版型在 `renderer.js`。

## 執行與檢查

不需安裝依賴。使用 Node.js 22 或更新版本：

```sh
npm run check
npm test
python3 -m http.server 8000
```

開啟 `http://localhost:8000`。請透過 HTTP 開啟，ES modules 不支援直接雙擊 HTML 的 file:// 開啟方式。

## GitHub Pages

在 repo 的 **Settings → Pages → Build and deployment → Source** 選 **GitHub Actions**。推送 main 或手動執行 **Check and publish GitHub Pages** 後會先檢查程式、執行測試，再發布網站。

預期網址為 `https://jutorliao-1991.github.io/jutor-scholarship/`，以 GitHub Actions 實際成功結果為準。

## 相容性

使用現代 Safari、Chrome、Edge、Firefox。HEIC 是否可讀取取決於瀏覽器；失敗時改用 JPG／PNG。Canvas 中文字型使用裝置內建字型，因此不同裝置的字形可能略有不同；文字會依實際測量結果縮排。瀏覽器分享與檔案儲存選項依裝置而異。

正式版合成過程不使用 AI、不重繪人物。早期 AI 風格樣張僅作設計方向參考，未作為網站照片或學生資料加入本 repo。
